`directLink` is the identity transport: it wraps the served router and invokes
handlers in-process, with no socket and no subprocess. That makes it the tool for
testing a surface — the client you drive in the test is the exact typed client a
socket consumer would hold.

## Build an in-process client

Implement the surface, flatten the fragment, and wrap it in `directLink`. Pass
it bare — `directLink` is the one link `surfaceClient` accepts without a watchdog,
because its transport is always-live.

```ts
import { implementSurface, inMemoryStore, inMemoryChannelByName, implement } from "@kolu/surface/server";
import { directLink } from "@kolu/surface/links/direct";
import { surface } from "../common/surface";

function makeTestClient() {
  const fragment = implementSurface(surface, {
    channel: inMemoryChannelByName(),
    cells: { load: { store: inMemoryStore(ZERO) } },
    collections: { processes: { readAll, upsert, remove } },
    procedures: { proc: { kill: async ({ input, ctx }) => ctx.collections.processes.delete(input) } },
  });
  const router = implement(surface.contract).router({ ...fragment.router });
  return directLink(router); // the raw typed client — the wire client, in-process
}
```

## Assert on a snapshot

A cell or stream read yields a snapshot first, then deltas, as an async
iterable. To assert on the current value, take the first frame. `firstFrameOrThrow`
(`@kolu/surface/first-frame`) does exactly that, and throws if the stream closes
empty — so a broken read fails the test instead of asserting on `undefined`.

```ts
import { firstFrameOrThrow } from "@kolu/surface/first-frame";

const client = makeTestClient();
const load = await firstFrameOrThrow(client.surface.cells.load.get({}));
expect(load).toEqual(ZERO);
```

## Drive a procedure and assert the effect

Procedures are plain awaited calls. Call one, then read the affected cell or
collection back and assert the new snapshot.

```ts
await client.surface.proc.kill({ pid: 4321 });

const alive = await firstFrameOrThrow(client.surface.collections.processes.keys());
expect(alive).not.toContain(4321);
```

## Read a run of stream frames

When the value under test is a stream that emits over time, iterate it and
collect the frames you care about. Because there is no socket, delivery is
deterministic — no timers, no flushing.

```ts
const frames: LogFrame[] = [];
for await (const frame of client.surface.streams.nodeLog.get({ nodeId })) {
  frames.push(frame);
  if (frame.done) break;
}
expect(frames[0].kind).toBe("snapshot");
```

<Aside type="tip" title="Same client, real transport later">
  Nothing above changes when the surface moves to a socket — the call sites are
  identical across links. A directLink test therefore also protects the wire
  contract: if a handler breaks, the in-process test catches it before a byte
  ever crosses a socket.
</Aside>
