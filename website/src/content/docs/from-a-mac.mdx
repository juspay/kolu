Your Mac is slow for agents, especially the filesystem. A headless box isn't,
and it stays up. Keep the Mac as the window. Kolu runs on the box, and you
open it from the Mac as a real app.

This is not remoting into a Linux desktop. There is no Linux GUI. Kolu is a
website the box serves; the Mac is a browser that you pin as an app.

You need a headless Linux machine with [Nix](https://nixos.asia/en/install)
(NixOS is common; any Linux with Nix is fine), a Mac, and a
[Tailscale](https://tailscale.com) account on both.

<Steps>

1. Run kolu as a user service on the Linux box.

   Import the home-manager module and enable it. The full module, logs, and
   address options are on [Deployment](/deployment#enable-the-service).

   ```nix
   { pkgs, kolu, ... }:
   {
     imports = [ kolu.homeManagerModules.default ];

     services.kolu = {
       enable = true;
       package = kolu.packages.${pkgs.stdenv.hostPlatform.system}.default;
     };
   }
   ```

   Apply the configuration, then open
   [http://127.0.0.1:7681](http://127.0.0.1:7681) **on the box** (or via ssh
   port-forward). You should see an empty canvas. That is kolu running.

2. Give it a private HTTPS URL with Tailscale Serve.

   Install Tailscale on the Linux box and on the Mac, signed into the same
   account. In the Tailscale admin console, turn on MagicDNS and HTTPS
   Certificates. On the box:

   ```sh
   tailscale serve --bg 7681
   ```

   Tailscale prints a tailnet URL:

   ```text
   https://your-box.your-tailnet.ts.net/
   ```

   Keep kolu bound to `127.0.0.1`. Serve is the only exposed surface. The
   longer tunnel notes are on [From another device](/remote-access).

3. Allow that origin, then rebuild.

   Tailscale presents a browser origin kolu did not start with. Add the
   **exact** URL from the previous step:

   ```nix
   services.kolu.allowedOrigins = [
     "https://your-box.your-tailnet.ts.net"
   ];
   ```

   Apply again. Without this, the page may load and then fail to talk to the
   server.

4. Open the printed URL in a browser on the Mac.

   Use the full `https://<machine>.<tailnet>.ts.net` address — not the bare
   machine name, and not the `100.x` address. Those stay plain HTTP and do not
   unlock install prompts, badges, or notifications.

5. Pin it as an app.

   In Chrome, Edge, Brave, or Arc: Install. In Safari 17+: File → Add to Dock.
   Browser-by-browser paths are on [Install as an App](/install-pwa).

   Kolu is now in the macOS Apps launcher, in its own window. The agents still
   run on the Linux box.

</Steps>

<Aside type="note" title="Already have kolu running on the box?">
  Skip the service step. Point Tailscale Serve at whatever port it is on, add
  that origin, and pick up from opening the URL on the Mac.
</Aside>
