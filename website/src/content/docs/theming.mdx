kolu ships the whole [iTerm2-Color-Schemes](https://github.com/mbadolato/iTerm2-Color-Schemes)
catalogue, over 200 themes, and lets you set one per terminal. When you run many
terminals at once, a distinct background is the fastest way to tell them apart.

## How a new terminal gets its theme

Two settings decide what a freshly opened terminal looks like.

### New terminal theme

This setting picks the strategy.

- **Inherit** copies the active terminal's theme, the way a new terminal
  inherits the active one's _size_. Set one theme you like and every new
  terminal follows it. With no terminal open there is nothing to copy, so the
  first one comes up in the built-in default (Tomorrow Night).
- **Shuffle** _(default)_ auto-picks a background perceptually distinct from
  every other open terminal, so two tiles never come up looking alike.

### Shuffle behaviour

This setting steers every shuffle: a shuffled new terminal, and the
<kbd>⌘⇧J</kbd> "shuffle this terminal" shortcut.

| Option | What you get |
| --- | --- |
| **Auto** _(default)_ | Picks stay in the app's current light or dark family, so a tile cannot surface as a bright-white panel in a dark workspace |
| **Dark** / **Light** | One family, whatever the app theme is |
| **Colourful** | Saturated tints only, skipping grey and monochrome schemes, across light and dark |
| **Random** | The whole catalogue |

Both settings govern every new terminal, not just the ones you open yourself. A
terminal an agent opens through the [MCP server](/mcp) picks up the same theme
policy, because kolu resolves it on the host where terminals live.

<Aside type="note" title="Switching light/dark is forward-only">
  Flipping the app between light and dark affects terminals you open
  afterward, never ones already on screen. **Auto** shuffle follows the
  light/dark mode of the browser tab you focused most recently, so a terminal an
  agent opens while no browser is watching stays in that family.
</Aside>

## The app theme

Separate from the per-terminal schemes, the app chrome follows a **dark**,
**light** or **system** preference. System tracks your OS setting, and the other
two pin it. This is the family the **Auto** shuffle stays inside.
