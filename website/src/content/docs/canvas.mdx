The desktop workspace is an infinite 2D plane. Terminals are tiles you arrange
freely: spread them out, cluster them by repo, or maximize one and cycle. There
is no separate edit mode, so the canvas is always live.

## Moving around

- **Pan** with two-finger scroll; hold <kbd>Shift</kbd> to force pan even when
  the cursor is over a tile.
- **Zoom** with pinch or <kbd>Ctrl</kbd> + scroll. Text selection, link
  hovering, and mouse input forwarded to TUI apps all land on the cell under
  your cursor at any zoom level. Your browser's own zoom is still
  <kbd>Ctrl</kbd> + <kbd>+</kbd> / <kbd>−</kbd> / <kbd>0</kbd>.
- A pinch over kolu's other surfaces (the dock, the right panel, the chrome
  bar, a maximized tile) or inside a previewed HTML file does nothing, rather
  than magnifying the page.
- Tiles **snap to a 24px grid** on drag and resize. Press <kbd>Esc</kbd> while
  dragging a tile to cancel the drag; the tile stays where it was.

## Opening terminals in place

- **Double-click any empty spot** on the canvas to open the command palette,
  already in the **New terminal** group. It is the same menu the dock's `+`
  button reaches, so you can pick a repo, name a worktree, or start in the
  current directory without leaving the plane.
- A new tile opens at the size of the terminal you are in now (the active one,
  not whichever was created last), so a layout you have tuned carries forward.
  Only the size carries over, not where the tile lands.

## Maximize

Double-click a tile's title bar to maximize it. That posture persists across
reloads. The tile you maximize is told the window's size; the tiles behind it
keep their own size and are not resized at all, going in or coming back out.
Switching terminals while maximized (from the dock, with
<kbd>Cmd</kbd>/<kbd>Ctrl</kbd> + <kbd>1</kbd>…<kbd>9</kbd>, or by cycling)
shows the tile you switch to at the window's size, once. The one you came from
is left as it was.

## Canvas, maximized, and the Conductor

The canvas and the maximized posture are the two postures of a **host** tab,
and the segmented control in the chrome bar switches between them. The first
tab in that row is [**`◆ Conductor`**](/conductor), kolu's one agent chat, which
takes the whole window when you select it (<kbd>Cmd</kbd>/<kbd>Super</kbd> +
<kbd>Shift</kbd> + <kbd>O</kbd> jumps there and back).

No canvas is shown while the Conductor is open, so the posture control and the
dock and inspector toggles are not drawn. The canvas stays as you left it. Its
tiles stop receiving live output after the same
[one-hour wait](/tiles#which-tiles-are-live) as any other trip away, and pick
it up again, repainted, when you return to that host. **Open tile** on one of
the agent's tool cards brings you back to the host tab that terminal is on,
focused on it.

## Arranging

Run **Arrange canvas by repo** from the palette to cluster each repo's tiles
into an island.

## What a tile's border tells you

Each live tile wears its agent's run-state as motion on its border, in the
tile's repo colour:

| State | The border |
| --- | --- |
| Working | The same double frame as the active tile (solid border and outer moat), with a calm rotating highlight on the outer rail |
| Needs you | A comet sweeps the ring, faster the fresher the wait. A missed alert throbs louder still |
| Just finished | A one-shot exhale that softens into a dim held ring, so a post-turn lull does not read as waiting on you |
| Idle | No glow |

With `prefers-reduced-motion`, every aura collapses to a static ring (finished
keeps the soft hold, without the pulse).

## New and sleeping tiles

New tiles land with a short brightness settle, so opening a terminal feels like
putting something down. Sleeping tiles fold, slightly desaturated and dimmed, so
you can see dormancy from the canvas as well as the title bar.

## The minimap

The minimap in the corner is both overview and heatmap: it marks tiles whose
agents are waiting or thinking, tints each rect with a touch of **repo colour**
so small tiles stay distinguishable, and carries the zoom / arrange /
activity-window controls. The bigger multi-agent workflow lives in
[Power Features](/power-features).
