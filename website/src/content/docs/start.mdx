Kolu is a terminal workspace for running many coding agents at once — real
terminals on a canvas, not a chat panel bolted to an editor. Two ways to get
there. Pick the one that matches what you have.

<CardGrid>
  <LinkCard
    title="Try it on this machine"

  />
  <LinkCard

  />
</CardGrid>

Once it is running, [First Five Minutes](/first-five-minutes) is the first
agent tile: open a repo, name a worktree, launch an agent, watch the dock.
