The **Code tab** is the file browser in the [right panel](/right-panel). It
shows the repo of whichever **pane** has focus, as a file tree over a
syntax-highlighted source view, so you can read what an agent is doing.

## Browse and jump

- Click a `path/to/file.ts:42` reference in terminal output to open that file at
  that line. A folder path such as `packages/client/` is clickable too, and
  reveals the directory in the tree.
- Rhai scripts (`.rhai`) are syntax-highlighted in both source and diff views.
- Big files and diffs highlight on a background worker, so a 50k-line lockfile
  paints immediately and never freezes scrolling.
- Right-click a file in the tree to **Copy path** or **Download** it. The save
  lands under the file's own name, whatever its type, on your machine or a
  [remote host](/remote-hosts). Folders offer no Download, and neither do files
  git reports as deleted.

## Your git changes, live

A segmented control switches between three views:

| View | What it lists |
| --- | --- |
| **All files** | The whole repo: what git tracks plus anything untracked, minus what your `.gitignore` hides. |
| **Local** | Your uncommitted changes. |
| **Branch** | Your changes against the base branch. |

The **Local** and **Branch** segments carry a change-count badge, so you can see
3 uncommitted files and 12 changes against your base without switching into
either.

The changed-file list and its diffs repaint the instant a file changes on disk.
Updates pause while the panel is hidden or the Inspector is selected, and
reopening Code refreshes it. The same loop works over the ssh hop to
[another machine](/remote-hosts).

Saving the open file updates it in place, keeping the viewer and its scroll
position.

### Filter the tree

Each view keeps its own tree, so expanded folders and scroll position survive
switching away and back. Typing in the filter box narrows the tree to matching
files and opens their folders.

A folder you close while filtering stays closed as git changes come in, until
the set of matching files changes. During loading or an error the previous tree
stays visible but dimmed, and cannot be clicked.

### See ignored files

The **eye toggle** beside the filter box brings back what `.gitignore` hides, as
dimmed rows. A fully-ignored directory arrives as one collapsed entry, so
`node_modules/` is one row rather than forty thousand files. Expand it and kolu
reads the one level beneath it from disk, a click at a time. The toggle
remembers itself per browser, and appears only in **All files**.

Nothing about an ignored file updates live, because kolu does not watch inside
ignored directories. Collapse a directory and open it again to re-read what is
inside it, and reselect a file to re-read its contents.

### A folder replaced by a file

When a directory was replaced by a file of the same name, or the other way
round, that path shows as one row:

- Its diff covers the file at that path and every file under it.
- The change-count badge still counts git's changed files, so it can read higher
  than the rows in the tree.
- A file renamed out of the replaced directory shows inside that row's diff as a
  plain deletion, because a diff of one path cannot pair the rename.
- A line reference copied from that diff names the file the line is in.
- Comments attach only to the path's own file. Select text in a file under it
  and the comment pill says so.

## Markdown and artifacts

| File | How it opens |
| --- | --- |
| `.md`, `.markdown`, `.mdx` | As a reading document, with a Source/Rendered toggle that holds your scroll position in both. A `---` front-matter block renders as a table, and a footnote marker opens its definition in a popover. |
| `.html` and `.svg` | Inline in a sandboxed iframe. The sandbox holds even when the file is opened on its own browser tab, so its scripts never get kolu's access. |
| `.pdf` | In the browser's native viewer. |
| images and video | As themselves. |

MDX is previewed as Markdown: component tags are not executed, and the
sanitizer strips them. Use **Source** for the raw MDX.

Previews live-reload on change. An external link in an HTML preview opens in a
new tab, and a link back into kolu itself does not.

## File comments

Select text in source, a branch diff, or a rendered artifact, and pin a quoted
note to it. The comment tray flushes to Markdown that you paste straight back
into the agent, with the file and line it was left on.
