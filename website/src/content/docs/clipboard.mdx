Many coding agents, such as Claude Code and Codex, take a **file path** on
their input line and read the file themselves. So paste an image or drop a
file: kolu saves it on the server and types its path into the terminal for the
agent to pick up.

## Paste an image

Press <kbd>Ctrl+V</kbd> in a terminal with an image on the clipboard. kolu saves
the image on the server and pastes its path into the terminal. Any agent that
accepts a pasted file path (Claude Code, Codex, …) picks it up as if you had
typed the path yourself, so a screenshot goes straight into the conversation.

## Drag and drop a file

Drag a file from your computer onto a terminal tile. It uploads to the server
and its path is pasted into the terminal, the same way a pasted image is.

- **Size cap** — 50 MiB per file. An oversize drop is rejected in the browser
  with a toast, and never hits the wire.
- **Type allowlist** — a curated set covering text, code, structured data,
  common documents, images, and video. A disallowed type is rejected the same
  way. These are the same image and video types the
  [Code tab](/code-tab) previews.

## What the agent sees

Both paths arrive as a **bracketed paste** on the input line: text for you to
review, not a submitted command. The agent reads the file from disk when you
send your prompt.
