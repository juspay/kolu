An agent asks a question (`AskUserQuestion`, `ExitPlanMode`); kolu shows an amber
count on the host tab and an orange mark on the dock entry. The signal exists but is
weak on both ends of what you ask:

- **Which agent?** The pill gives a count, never *which* — you scan the dock by eye.
- **Is it important?** The asking mark is the faintest pip in the palette (6px, 55%
  opacity), while the lower-stakes *unread* badge pulses.<Footnote>`PIP_BODY.awaiting` is `w-1.5 h-1.5 rounded-full bg-alert/55` — <Cite file="packages/solid-statepip/src/pipVariant.ts" line={93} />. The loudness hierarchy is inverted.</Footnote>

Both fix off facts the client already holds — no wire field, no new sensing. This
ships **AD1** + **AD2**; the question *text* (**option 3**) is deferred.

## AD1 — the awaiting pill becomes a jump button

The `urgency` cell already carries the waiting terminals' *ids*
(`{ awaitingIds }`), <Cite file="packages/padi/src/urgency.ts" line={28} /> but the UI
projects them down to `.length`. <Cite file="packages/client/src/host/useHostAwaiting.ts" line={24} /> So AD1 is wiring:

- `useHostAwaiting` returns the ids; the three readers use `.length` for the badge.
- `HostAwaitingPill` gains `onActivate` and renders as a `<button>`. In `HostChip` it
  moves out of the `role="tab"` button to a sibling, so no button nests in a
  button.<Footnote>The remove-`✕` is already a sibling of the tab button for the same reason (nested interactive elements are invalid HTML). AD1 follows that precedent.</Footnote>
- Clicking runs `setActiveHost` then `tileStore.activate`, cycling `awaitingIds` — the
  same switch-then-activate seam the cross-host notification click uses,<Footnote>`useHostAttention`'s `notify.onClick` does `setActiveHost` then `focusTerminal` (the store's `activate`) — <Cite file="packages/client/src/host/useHostAttention.ts" line={144} />. AD1 reuses it rather than inventing a second focus path.</Footnote> so a badge
  click and a notification click behave identically.

## AD2 — a genuinely-blocked agent gets its own pip

The paint fold collapses two states into one amber dot: **blocked on your answer**
(`awaiting_user`) and **just finished** (`waiting`). <Cite file="packages/terminal-vocab/src/agentProjection.ts" line={116} /> The
lingering dim glow for a finished agent is correct; the bug is that the one asking
*now* whispers at the same volume. AD2 splits only the loud end out:

- A new `blocked` pip variant in `@kolu/solid-statepip` — full-opacity, larger,
  pulsing — versus the unchanged dim `awaiting` dot.
- Promoted through the existing `agentBucket` fence (`awaiting_user → "awaiting"`),
  <Cite file="packages/terminal-vocab/src/agentProjection.ts" line={72} /> so
  `paintDockRow` and `agentPipVariant` promote to `blocked` and everything else folds
  through the shared paint class unchanged.

<Callout kind="accent" title="Why not split the shared AgentPaintClass?">
Wrong-sized cut: `AgentPaintClass` also feeds the tile aura, minimap, and switcher
columns, so `blocked` there forces a new switcher column and a louder aura on every
tile. Keeping it **dock-local** (`DockRowBucket` + the tile-title pip) touches only
the two surfaces in the complaint. The *dock row pip ≡ tile-title pip* parity holds,
because both promote through the same `agentBucket` check.<Footnote>Pinned by the parity test at <Cite file="packages/client/src/canvas/dock/dockRowRanking.test.ts" line={236} />.</Footnote>
</Callout>

## Option 3 — the question text — is deferred

Showing the question in the dock subtitle is a bigger, brittler pass. The plumbing is
cheap (one nullable field + a one-line `rowSubline.ts` change), but **the text isn't
readable while the question is pending**: kolu tails the JSONL transcript, and the
Claude Agent SDK buffers the `AskUserQuestion` block off-disk until you
answer. <Cite file="packages/integrations/claude-code/src/agent-adapter.ts" line={73} /> The
only live source is the rendered screen, which the adapter scrapes for *footer chrome*
only, no text. <Cite file="packages/integrations/claude-code/src/screen.ts" line={101} /> Extracting
the body means a version-sensitive parser that buys only Claude Code.

<Callout kind="note" title="If we ever do it, use a hook not a scraper">
A `PreToolUse` hook on `AskUserQuestion` hands over the exact text non-brittly — but
the adapter uses no hooks today, so it's a new integration mechanism, and its own
note.
</Callout>
