Found live by srid while dogfooding DL2 (#1864): click a deep link to a
terminal, press mouse-back, land somewhere unrelated. Root cause split in two —
one bug (fixed), one design question (this note).

## The bug (fixed in DL2)

Deep-link routing pushed a browser-history entry per link while ordinary
navigation recorded nothing, so the history stack was a list of stale teleport
commands; back replayed the *previous link*, not the previous place. Fixed by
reflecting external hashes via `history.replaceState` — the URL stays durable
and copyable, but links never push entries.

## The design question — one button, two meanings

- **Pointer over a Code-tab preview**: the sandbox traps mouse X1/X2; the
  in-iframe SDK forwards them and kolu drives the **file browser's own
  back/forward** — back means "previous previewed file". A deliberate feature
  (`artifact-sdk/client/bridge.ts` — "so the buttons behave the same over a
  preview as over the file tree").
- **Pointer anywhere else**: the browser's real back — which, post-fix, walks
  whatever history the browser has (usually: out of kolu).

Two meanings selected by hover position is the confusion to kill. The options:

1. **Back = browser back, everywhere.** Drop the preview's X1/X2 capture; the
   file browser keeps its own visible back/forward buttons in the Code-tab
   chrome. Cheapest; loses the (genuinely nice) mouse-back-over-preview flow.
2. **Back = app history ("where I actually was"), everywhere — a real DL3.**
   Ordinary navigation (terminal focus, host switch, panel/file changes)
   writes history too, so back/forward walk your real path through kolu. Needs
   a definition of a *place*<Footnote>Candidate: `{host, terminal,
   right-panel tab + file}` — exactly the state the deep-link grammar can
   already express, which is what makes this DL3-shaped: every place is a
   deep link, and back/forward walk deep links you actually visited.</Footnote>
   and touches every navigation site; the view-only law is preserved (history
   entries mirror state, never mutate it).
3. **Keep the split, but make it visible** — status-line hint while hovering a
   preview. Recorded for honesty; weakest option.

Recommendation: **option 2 as the DL3 plan** (the place-is-a-deep-link framing
makes it small and principled), with option 1 acceptable as an interim if DL3
doesn't get scheduled. srid rules.
